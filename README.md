# StarLight: True-Sky 13-Sign Astronomical Engine

A high-precision JavaScript calculation engine for true astronomical constellation boundaries, incorporating 13-sign planetary placements, Ophiuchus coordinates, and Lilith/Eve relationship polarities.

## Features
- **True Astronomical Boundaries:** Calculates real-time planet and luminary positions based on true constellation boundaries rather than standard 30-degree tropical segments.
- **13-Sign System Support:** Full integration of Ophiuchus along the ecliptic path.
- **Tropical vs. True Sky Comparison:** Side-by-side positioning engine for traditional 12-sign vs. astronomical true-sky charts.
- **Export & Web Tools:** Lightweight client-side rendering for visual wheel graphics and planetary aspect summaries.
